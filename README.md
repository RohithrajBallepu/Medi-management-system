Hospital Management System
A web application built with Spring Boot and JavaScript to manage patients, doctors, and appointments.

Features
Manage patient records easily

Schedule and manage doctors

Book and track appointments

RESTful API backend with Spring Boot

Installation
Clone the repository:

text
git clone https://github.com/RohithrajBallepu/Medi-management-system.git
Go to the project folder:

text
cd Medi-management-system
Make sure Java JDK 11 or higher is installed.

Run the backend:

Windows:

text
.\mvnw.cmd spring-boot:run
macOS/Linux:

text
./mvnw spring-boot:run
Open the frontend files from src/main/resources/static in your browser.

Usage
Use the web pages to add and view patients, doctors, and appointments. The backend runs at http://localhost:8080 and serves all the APIs.
